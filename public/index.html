Idle

Synthetic data only. The agent talks to the caseworker after an interview, never to the survivor. It can propose a field; only code can write it: the quote must match words the caseworker said, the value must be read back aloud, and the caseworker must say yes.

      What TRACE Debrief will not do
      • Talk to survivors, or listen during the interview.
      • Record the caseworker's impression as something the survivor said. Hedged speech ("I think…", "je pense…") is kept apart by code.
      • Judge credibility from hesitation, pauses, tone or speech timing. No timing feature is computed.
      • Store names, phone numbers or addresses. Only a pseudonymous case code.
      • Decide trafficking status. Indicators are an aid; high-risk cases go to a supervisor.
